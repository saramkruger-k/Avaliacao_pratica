# SUNRISE #28782 — Equipe de FTC SESI SENAI SC

Página web temática sobre a equipe de robótica **SUNRISE #28782** do FIRST Tech Challenge (FTC), vinculada ao SESI SENAI SC em Joinville (SC).

## Estrutura do projeto

- `index.html` — Estrutura HTML5 semântica com seções sobre a equipe, conquistas, galeria e simulador de pontuação.
- `css/style.css` — Folha de estilos da aplicação (a ser implementada na Etapa 3).
- `js/script.js` — Script de validação, cálculo e tratamento de exceções do simulador (a ser implementado na Etapa 4).
- `img/` — Diretório reservado para as fotografias da equipe (a ser preenchido na Etapa 2).
- `README.md` — Documentação inicial do projeto.

## Origem das imagens

As fotografias armazenadas em `img/` (`sunrise-02.jpg`, `sunrise-04.jpg`, `sunrise-06.jpg`, `sunrise-10.jpg` e `sunrise-13.png`) foram fornecidas pela própria equipe **SUNRISE #28782 (SESI SENAI SC)** via Google Drive.
